# mehro

i liked this site, so i took it. i've replaced everything that mattered with my own style and my own links. it’s my corner of the internet now, don't bother looking for the old one.

## what it does

- serves the website frontend
- runs a small backend for dynamic stuff
- shows discord presence data

## stack

- node.js + express
- discord.js
- plain html/css/js

## local setup

1. install deps
   - `npm install`
2. copy env template
   - `cp .env.example .env`
3. fill in your values in `.env`
4. run the app
   - `npm run dev`

by default it runs on port `3001` unless you change it in env.
